## 2. ケースの詳細

幅のケース(001〜007)は、幅ごとに新しいブラウザコンテキスト(保存データなし)で、スタート → フリー 課題 1 → クリア → スタート → セット A → 結果 の順に画面を開いて計測する。

### FC-MOB-001〜004 横スクロールしない

- 期待結果: `document.documentElement.scrollWidth` と `document.body.scrollWidth` が `window.innerWidth` 以下。画面の右端を越える要素が、横スクロールする枠(盤面・表・手札)の中以外に無い

### FC-MOB-005 盤面の横スクロール

- 期待結果: `#board-scroll` の `scrollWidth` が `clientWidth` より大きく(盤面 26 列 = 884px が枠より広い)、本文は横にスクロールしない

### FC-MOB-006 / 007 操作要素の大きさ

- 対象: スタート画面と課題画面で表示中の `button`・`a`・`input`・`summary`
- 期待結果: 006 は幅・高さとも 24px 以上。007 は 44px 以上(満たさないものを一覧にする)

### FC-MOB-010 手札から盤面へドラッグ

- 前提: 幅 390px。練習 1 を開く。盤面は空
- 手順:
  1. 手札の Start を指で押さえ、盤面の 0 行 2 列へ動かして離す(タッチ開始 → 12 回の移動 → 終了)
  2. 必要なら、手札と置き先が同時に画面に入るように画面をスクロールしてから行う
- 期待結果: 盤面に Start が 0 行 2 列に置かれる。手札と置き先が同時に画面に入らない場合は NG として記録する

### FC-MOB-011 盤面のカードを動かす

- 前提: 010 の続き
- 手順: 盤面の Start を押さえ、0 行 4 列へ動かして離す
- 期待結果: Start が 0 行 4 列に移る

### FC-MOB-012 盤面の外へ出して手札へ戻す

- 前提: 011 の続き
- 手順: 盤面の Start を押さえ、盤面の枠の上(お題の文のあたり)へ動かして離す
- 期待結果: 盤面が空になる

### FC-MOB-013 置けないマスへドラッグ

- 前提: 盤面に Start(0 行 2 列)がある
- 手順: 手札の End を押さえ、0 行 3 列(Start と重なる)へ動かして離す
- 期待結果: 盤面は Start 1 枚のまま

### FC-MOB-014 タップで選んで置く

- 手順: 手札の `a` をタップ → 盤面の 1 行 0 列をタップ
- 期待結果: `a` が 1 行 0 列に置かれる。選択は解除される

### FC-MOB-015 盤面のカードを選んで「手札に戻す」

- 手順: 盤面の `a` をタップ → 選択バーの「手札に戻す」をタップ
- 期待結果: 盤面から `a` が消える

### FC-MOB-016〜019 ボタンとダイアログ

- 016 はフリー 課題 1 で行う(練習ではダイアログが出ない)。017 は盤面に 1 枚置いてから。018 は練習 1 の正解例を置いた状態で INPUT に 3 を入れ、出力に 6 が出ること。019 は確認で「やめる」をタップした後も `#s-play` が表示されていること

### FC-MOB-020 練習 1 を通しでクリア

- 手順: 練習 1 の正解例の 9 枚を、手札からのタッチドラッグで順に置く(ドラッグできない配置はタップで置き、その旨を記録する)→「判定する」をタップ
- 期待結果: クリア画面(`#s-clear`)が表示される

### FC-MOB-021 チャレンジを通しで結果画面まで

- 手順: スタートの「セット A を始める」をタップ → 課題 1 の正解例をタップで置く → 判定 → クリア画面の「次へ」をタップ → 課題 3 で「あきらめる」→ OK → 課題 5 で「あきらめる」→ OK
- 期待結果: 結果画面(`#s-result`)が表示され、1 / 3 問クリアと出る

### FC-MOB-022 再読み込み

- 手順: フリー 課題 1 で Start を置く → 再読み込み
- 期待結果: 課題画面のまま、盤面に Start がある
