カードのデザイン案

フローチャート工房 v1.0。英語のラベルと日本語の添え字、仲間ごとの色。色の値は 2026-10-17 に確定(仕様 §3.2)

仲間ごとのカード

実際の大きさです。1 マスは幅 34px、カードの高さは 50px(添え字を入れるため、前の版の 44px から高くした)。数字は 2 けたまで 1 マス、3 けた以上は 2 マス。= と == は添え字を入れるため 2 マス。

盤面に並べたとき

正解例をそのまま盤面に置いた見え方です。どこが分岐で、どこがくり返しかを色で追えるかを確かめます。

デザインの決まり

  • 形は流れ図の記号に寄せる。Start / End は端子、IF は判断、PRINT は表示、LOOP はループの始まり、CONTINUE と BREAK はループの終わりの形。
  • 色は一緒に使う仲間ごとに 1 色。条件分岐は紫、ループは朱、出力は藍、変数は緑、数値は茶、記号は灰青。Start / End は色を付けない墨色。
  • 命令のカード(IF・LOOP・CONTINUE・BREAK・PRINT)は塗りつぶし。目印と部品(Yes・No・ことば・変数・数値・記号)は淡い地と枠にする。
  • 日本語の添え字は英語のラベルの下に置く。取り違えやすい = (入れる)と == (等しい)にも意味を添える。ほかの記号・変数・数字・ことばには付けない。
  • 色だけに頼らず、形とラベルでも仲間が分かるようにする。
