フローチャート工房

カードを並べてプログラムの流れを組み立てるパズル

スタート

カードを並べて、お題どおりに動く流れを組み立てる

  • 手札のカードを盤面に並べてプログラムを作り、「判定する」で確かめます。全部のテストケースに合格すればクリアです。判定は何度でもできます。
  • 練習でカードの置き方を覚えたら、フリーで 10 問を好きな順に解きましょう。チャレンジでは、限られた手札で 3 問を続けて解きます。
  • ★ は 3 つ。クリア、基準の枚数以内、ヒントを見ずに基準の時間以内。時間切れはないので、じっくり考えても大丈夫です。

盤面の読み方

  • 上から下へ読みます。1 行に 1 つの命令を、カードをすき間なく横に並べて作ります(例: a = INPUT % 10)。
  • Start の下の行から読み始めます。1 行空けると、そこで道が途切れます。
  • IF の行のすぐ下に Yes と No を置くと、左右に道が分かれます。分かれた道は合流しません。Yes / No の右に続けて命令を置いてもかまいません。
  • End は一番下に 1 枚あれば、すべての道の終わりになります。
  • CONTINUE で LOOP の直後へ戻り、BREAK でくり返しを抜けてそのカードの下へ進みます。
  • 計算は × ÷ % が先で、同じ強さなら左から順に計算します。÷ は小数点以下を切り捨てます。= は右の値を左の変数に入れ、== は等しいかを調べます。
